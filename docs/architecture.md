# PROJECT PLUTO

Electron desktop, bundled React UI, private local workspace. macOS and Windows use the same application code. The renderer calls a fixed action through a sandboxed preload. The main process validates the sender and dispatches. Remote employer pages live in a separate, isolated window with no preload.

## Module contracts
Main injects Electron dialogs and storage into each service. JavaScript modules use ESM except the preload. JSX panels are default exports. IPC accepts a single object per action. The renderer uses window.pluto.call(action, payload); it throws on failure. Each panel receives {notify, refresh, state}. notify(message) reports outcomes; refresh() reloads the workspace.

- workspace.mjs exports createWorkspace(directory). Methods (synchronous unless otherwise documented): snapshot() returns {profile, jobs, notes, schedule}; saveProfile(profile), saveJob({id?, company, title, url, description?, location?, salary?, stage?, evidence?, interviewAt?, draft?, resumeText?}), saveNote({id?, title, body, jobId?}), saveSchedule({enabled, hour, minute, query, lastRunDate?}), exportVault(directory), importVault(directory), close(). Stages Saved, Preparing, Applied, Interview, Offer, Closed. snapshot jobs include id, createdAt, updatedAt. Store actual application receipts, interviews and submitted resume snapshots. Caller passes evidence for moving into Applied. Notes are Markdown; no HTML interpretation. Dates are ISO. Profile may initially be null or {}. No secrets in this store.
- desktop/providers.mjs and ui/Connections.jsx: provider AI, Firecrawl config and operations. createProviders({secrets, prefs}) returns {settings(),configure(payload),disconnect(payload),test(payload),draft({profile,job}),search({query})}. settings() returns only public settings. search returns [{title,url,description}]. draft returns string. secrets has async get(key),set(key,value),remove(key); prefs sync get(key),set(key,value). Action names providers.settings/configure/disconnect/test/draft/search. Use official APIs, allow https custom OpenAI-compatible endpoint and http loopback for Ollama. Don't let a changed endpoint reuse a previous key without permission. UI provider connection controls only; parent handles discovery/drafting.
- desktop/mail.mjs and ui/Mail.jsx implement email accounts (Gmail, Outlook), optional job-related read-only message sync, account identity, local disconnect. createMail({secrets,prefs,openExternal}) returns {settings(),connect(payload),disconnect(payload),scan(payload)}. Actions mail.settings/connect/disconnect/scan. Mail UI is a workspace tab and can record explicitly matched outcomes (workspace.saveJob). No hidden mail reads.
- ui/Profile.jsx and desktop/resume.mjs implement résumé-first setup and optional selected history excerpts. createResume({dialog,window}) returns {pick()} (window is getter). Action resume.pick. Profile pane receives {state,refresh,notify}. workspace.saveProfile accepts object with name,email,phone,summary,resumeText,targetRoles,location plus other reviewed fields. User confirms before saving; pass plain strings for targetRoles and location. No other private data by default.
- Main owns runtime, secret storage, release, discovery/case UI, application browser and the scheduler. Workspace public actions workspace.snapshot/saveJob/saveNote/saveProfile/saveSchedule/importVault/exportVault; vault actions prompt for the directory in main. Application browser action application.open({id}). app.openExternal({url}) accepts only web URLs. No generic filesystem, network or script execution IPC.

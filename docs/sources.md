# Where Pluto looks for jobs

In **Discover → Sources**, paste a public job list or careers page and choose **Add source**. To try the Simplify list, select **Use the Simplify new grad list**, then **Add source**. Enter a role or location and choose **Search saved sources**.

Each result shows where it came from. **Review role** opens an application draft. Check the employer’s posting for current availability and eligibility before applying.

## Which pages work

Pluto reads public GitHub job lists through GitHub. This needs no connected account or Firecrawl credits. It looks for job tables with application links, including the Simplify new grad list. A README that contains only general career advice may return zero matches. [Simplify new grad positions](https://github.com/SimplifyJobs/New-Grad-Positions)

For public job websites, connect Firecrawl under **Connections**. Each enabled website can use a scrape from that account when a search runs. A board may require sign-in, block readers or load its listings on another page. Paste the public page that actually lists openings. Pluto reports errors by source and retains matches from pages it could read.

## Daily discovery

Enable **Daily discovery** and save a query and local time. While Pluto is open, the scheduled search uses the same enabled sources as a manual search. Clear a source’s checkbox to pause it. **Remove** deletes it from the list and preserves jobs you already saved. With an empty source list, Discover uses its original Firecrawl web search. With every saved source paused, Pluto skips them all.
